## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.

To verify a change visually (screenshot a page), use the `.claude/skills/run/SKILL.md` skill at the repo root — `chromium-cli` is not available in this environment, so it drives the app with Playwright instead.
